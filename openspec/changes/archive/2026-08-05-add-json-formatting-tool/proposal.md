## Why

当前编码工具覆盖 URL、Base64、JWT 等文本处理能力，但开发者在调试接口响应、配置片段和日志载荷时，还需要一个更顺手的 JSON 工作台：把紧凑 JSON 格式化为可读文本，同时在同一个窗口中查看树状结构，快速定位任意层级并复制局部内容。

JSON 字符串转义和去除转义也常出现在接口调试、日志排查和嵌套 JSON 字段处理中。把这些能力放在“编码工具”分组下，可以让文本编码、令牌和结构化数据处理保持同一入口。

## What Changes

- 在“编码工具”分组中新增 `JSON` 工具，排列在 `JWT` 之后。
- JSON 工具页面使用中文界面文案。
- JSON 格式化在同一个工作窗口内完成：输入、格式化结果和树形结构不拆成不同页面或彼此割裂的流程。
- 格式化视图采用左右布局：左侧处理 JSON 输入和文本结果，右侧展示树形结构。
- 树形结构按对象、数组、字符串、数字、布尔值和 null 展示 JSON 内容，并支持对任意对象或数组层级独立展开/折叠。
- 折叠后的对象或数组节点显示小框标识，说明折叠内容包含多少个子元素或属性。
- 右侧树形结构需要保持紧凑的代码式视觉密度；隐藏复制控件、反馈提示或其他不可见元素不得撑大树节点行距。
- 右侧树形结构提供一个全局展开/折叠切换按钮：初始为“全部折叠”，当树已全部折叠时切换为“全部展开”。
- 为 JSON 中的每个部件提供复制能力：可复制完整格式化 JSON、压缩 JSON，以及任意树节点对应的 JSON 片段或原始标量值。
- 新增 JSON 转义与去除转义能力：将文本转换为可嵌入 JSON 字符串的转义内容，或将 JSON 字符串字面量/转义内容还原为普通文本。
- 所有处理均在浏览器本地完成，不上传、不持久化用户输入。

## Capabilities

### New Capabilities

- `json-tool`: 定义 JSON 解析、格式化、压缩、同窗口左右布局、右侧树形查看、紧凑树行距、任意层级折叠、全局展开/折叠切换、折叠计数标识、节点复制、JSON 字符串转义和去除转义的本地工具行为。

### Modified Capabilities

- `grouped-tool-navigation`: 在“编码工具”分组末尾新增 `JSON`，桌面与移动导航、首页能力概览保持相同顺序。

## Impact

- 新增 JSON 领域逻辑模块、React 工具页面、树节点组件、样式和测试。
- 扩展应用工具 ID、编码分组导航、首页展示和导航顺序测试。
- 页面文案需要统一为中文，包括按钮、状态反馈、字段标签、树节点操作和错误提示。
- 不计划新增运行时依赖；优先使用 `JSON.parse`、`JSON.stringify` 和现有复制/面板 UI。
- 需要注意大 JSON 的渲染性能、树节点折叠状态管理、全局展开/折叠切换、树行视觉密度和复制反馈稳定性，首版以合理输入规模和可恢复错误反馈为边界。
