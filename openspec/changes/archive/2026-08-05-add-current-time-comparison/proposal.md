## Why

当前时间戳工具只能通过转换操作查看时间值，不便于快速对照“本地 ISO 时间”、“GMT/UTC ISO 时间”和“Unix 时间戳”。在页面底部提供一组实时对照值，可以让用户无需输入或转换即可查看和复制当前时间。同时，转换区当前预填当前时间戳且使用多行输入/输出框，在内容通常只有一行时造成了不必要的垂直空间。

## What Changes

- 在时间戳工具最底部新增紧凑的“当前时间对照”功能区。
- 按从上到下的固定顺序显示带本地时区偏移的 ISO 8601 当前时间、GMT/UTC ISO 8601 当前时间，以及 Unix 毫秒时间戳。
- 定期刷新三个值，使它们始终表示同一个当前时刻。
- 每行右端提供与 MD5 结果行一致的纯图标复制按钮，包含可访问名称、键盘操作和不引起布局跳动的成功/失败反馈。
- 在窄视口下保持三行值可读、复制按钮可操作，且不产生水平页面溢出。
- 时间戳转换输入在页面初始显示时保持为空，不再自动预填当前 Unix 毫秒时间戳。
- 将转换区的输入和输出框缩减为适合单行时间戳或日期文本的紧凑高度，同时保持长 ISO 8601 或自定义日期值可完整查看和编辑。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `timestamp-conversion`: 在时间戳页面增加当前时刻的本地 ISO、GMT/UTC ISO 和 Unix 毫秒时间戳对照显示、定期刷新与独立复制行为，并将转换区调整为空初始输入与单行紧凑框。

## Impact

- 影响时间戳功能的 React 组件、时间格式化辅助逻辑、样式与组件/单元测试。
- 额外影响时间戳转换表单的初始状态、输入/输出控件高度与紧凑布局回归测试。
- 复用或抽取现有 MD5 摘要行的紧凑输出与图标复制视觉语义。
- 不增加后端、网络请求或新的运行时依赖；所有时间计算与复制操作均在浏览器本地完成。
