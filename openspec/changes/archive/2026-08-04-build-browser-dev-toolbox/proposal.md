## Why

常见的编码、摘要、非对称密码和时间转换操作目前缺少一个统一、易用且不上传数据的界面。构建一个纯前端工具箱，可以让开发者在浏览器中离线、安全地完成这些高频操作，并减少在多个网站或命令行工具之间切换。

## What Changes

- 新增单页前端工具箱，以统一导航承载 Base64、MD5、SHA-1、RSA、时间戳和 URL 编解码功能。
- Base64 支持 UTF-8 文本的双向转换，并对无效输入给出明确错误。
- MD5 同时输出十六进制摘要的大小写版本；SHA-1 输出十六进制摘要并提供大小写版本。
- RSA 支持生成 2048 位密钥、导入/导出 PEM 密钥、公钥加密与私钥解密，以及私钥签名与公钥验签。
- 时间转换支持秒级/毫秒级时间戳、UTC/本地时区、自定义日期格式，以及日期文本反向转换为时间戳。
- 时间解析与格式化支持常用的完整 ISO 8601 日期时间表示，包括日期、时间、毫秒、`Z` 和 `±HH:mm` 时区偏移。
- URL 编解码同时支持完整 URL 和 URL 组件两种语义。
- 所有计算均在浏览器本地执行，不将输入、输出或密钥发送到服务器。
- 对 MD5、SHA-1 的安全局限及 RSA 明文长度限制提供界面提示。

## Capabilities

### New Capabilities

- `text-encoding`: Base64 与 URL 的双向编码、解码及输入错误处理。
- `hash-digests`: MD5 和 SHA-1 文本摘要计算、大小写结果展示及安全提示。
- `rsa-cryptography`: RSA 密钥生成和 PEM 导入导出，以及加密、解密、签名和验签。
- `timestamp-conversion`: 时间戳与自定义或 ISO 8601 日期文本之间的双向、时区明确的转换。
- `toolbox-shell`: 工具导航、统一操作反馈、本地处理与响应式界面行为。

### Modified Capabilities

无。

## Impact

- 新增前端应用结构、页面组件、状态管理、样式和测试。
- 引入浏览器 Web Crypto API 用于 SHA-1 和 RSA；MD5 需要独立的轻量实现或依赖。
- 引入严格的自定义格式与 ISO 8601 日期时间格式化、解析能力，避免依赖实现不一致的浏览器日期字符串解析。
- 应用可构建为静态资源并部署到任意静态托管服务；无需后端 API 或持久化数据库。
