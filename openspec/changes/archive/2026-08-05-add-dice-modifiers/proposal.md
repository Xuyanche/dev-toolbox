## Why

当前色子模拟器只能表达和合计骰子点数，无法直接处理角色属性、难度或其他常见的整数补正。在表达式和可视控件中加入同一个补正值，可以让用户直接构造并核对完整的投掷结果。

## What Changes

- 扩展骰子表达式，允许在一个或多个正向骰子项之间/之后使用 `+` 或 `-` 连接整数项；所有整数项的代数和为当前补正。
- 支持 `1d6+2`、`1d6-3` 和 `1d6+3-5` 等表达式，应用后将同面骰子合并，并将多个整数项规范化为一个净补正；净补正为 0 时从规范化表达式中省略。
- 表达式只支持加减法；骰子项只允许正向相加，禁止减去骰子；补正必须是可为正、负或零的安全整数。乘除、括号、小数及其他语法均拒绝。
- 在可视骰子选择区的右侧增加紧凑的“补正”整数输入框，修改它时立即同步表达式，应用表达式时也反向同步该输入。
- 投掷结果的总点数计入补正。当补正非 0 时，在各骰子结果的最后一行显示带符号的补正值；未输入或补正为 0 时不显示该行。
- “清空色子”同时清空骰子池、表达式和补正；“清空结果”仍仅移除投掷结果，保留当前骰子与补正配置。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `dice-simulator`: 扩展骰子表达式语法与可视配置，并将整数补正纳入投掷结果和总点数。

## Impact

- 影响骰子域模型的表达式解析/格式化、投掷结果结构和总点数计算。
- 影响色子模拟器的 React 状态同步、选择区布局、结果呈现及相关单元/组件测试。
- 不更改支持的骰子面数、单次 10,000 颗上限、本地无偏随机语义，且不增加新依赖或网络请求。
