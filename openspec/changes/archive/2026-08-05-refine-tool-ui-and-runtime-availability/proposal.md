## Why

JSON 与对称加密页面的文本框操作样式不一致，AES/SM4 的输入输出区域也会因标题操作和 IV 提示结构不同而错位。同时，当前静态工具目录无法由部署环境控制可见性，导致 DES 等不希望默认开放的工具只能通过重新构建隐藏。

## What Changes

- 将 JSON 输入复制图标从文本框内部移到字段标题区域，采用 JWT 页面一致的外置图标操作样式。
- 统一 AES、SM4 明文/密文输入与结果区域的标题、框体高度和图标操作；为可编辑区域提供复制与删除图标，为只读结果提供复制图标。
- 对不使用 IV/计数器/nonce 的模式保留参数栏结构并禁用无效控件，不再使用绿色提示框替代参数输入。
- 为 AES 增加 ECB 模式，支持 PKCS#7 与无填充，并明确不使用 IV。
- 引入部署时可修改的运行时工具开关配置，统一控制桌面导航、移动导航、首页目录和工具内容挂载；DES 内置默认关闭，其余工具默认开启。
- 规定配置缺失或无效时的安全回退、空分类隐藏以及当前工具被关闭时返回首页的行为。

## Capabilities

### New Capabilities

- `runtime-tool-availability`: 定义静态部署环境下通过运行时配置文件启用或关闭工具页面的加载、校验、回退与一致呈现行为。

### Modified Capabilities

- `json-tool`: 将统一输入框的复制操作改为文本框外的字段标题图标，并保持复制与反馈语义。
- `symmetric-cryptography`: 增加 AES-ECB，统一明/密文区域操作与对齐，并调整无模式参数时的禁用展示。
- `grouped-tool-navigation`: 让桌面和移动导航只呈现运行时启用的工具与非空分类，同时保持剩余工具顺序和可访问性。
- `toolbox-homepage`: 让首页能力目录与运行时启用工具保持一致，不宣传已关闭的工具。

## Impact

- 影响 `src/features/json/JsonTool.tsx`、`src/features/symmetric/`、共享字段图标组件与相关响应式样式。
- 影响 `src/shell/App.tsx` 的工具注册、导航和内容挂载，以及 `src/features/home/HomePage.tsx` 的目录数据来源。
- 新增由静态服务器提供的运行时 JSON 配置加载入口和类型校验；不引入业务后端、账号、持久化或用户数据传输。
- 需要更新 JSON、JWT、对称加密、导航、首页及配置失败回退的组件与集成测试。
