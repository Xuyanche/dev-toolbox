## Why

JSON 工具当前在页面顶部堆叠说明提示和模式选择，并使用固定的大输入区与分离的转义工作区，导致桌面用户需要滚动页面才能完成常用操作。将这些操作集中到一个随视口伸缩的工作区，可以降低空间浪费并提高格式化、压缩、复制和转义的连续操作效率。

## What Changes

- 删除 JSON 工具的“JSON 模式”选择以及独立的转义输入、输出页面，保留一个统一的 JSON 输入工作区。
- 在 JSON 输入框下方集中提供“格式化 JSON”“压缩 JSON”“转义”“去除转义”和“清空”操作；各转换直接替换当前输入框内容。
- 格式化或压缩成功后更新右侧树形结构；转义、去除转义或清空后清除旧树形结果，避免树内容与输入不一致。
- 删除“复制格式化结果”和“复制压缩结果”文字按钮，在输入框内提供仿照 SHA 摘要结果的图标复制操作，复制当前输入框的完整内容。
- 将树节点的文字复制控件统一改为具有可访问名称的图标控件，并保持悬停、键盘聚焦和复制反馈不会增加树节点间距。
- 合并 JSON 转换、复制及错误反馈为一个稳定的反馈区域，避免重复反馈行占用空间或引起布局跳动。
- 让 JSON 输入区与树形区在桌面视口内使用匹配的可用高度并分别内部滚动；在至少 1280×768 的桌面视口中，主要输入、查看和操作控件无需滚动整个页面即可使用。
- 删除 JSON 与 JWT 页面顶部的彩色“本地处理”提示；继续通过页面说明、侧边栏、介绍首页和全局页脚传达本地处理原则，并保持所有本地处理和敏感数据安全约束不变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `json-tool`: 将格式化、压缩、复制、转义和去除转义整合到紧凑的单页工作区，并定义桌面首屏、图标复制及统一反馈行为。
- `jwt-tool`: 移除页面顶部独立的本地处理提示，同时保留本地敏感数据处理行为和其他安全提示。

## Impact

- 影响 JSON 工具组件状态、操作布局、复制控件、树状态更新、反馈区域、响应式样式和组件测试。
- 影响 JWT 页面顶部提示结构及相关可见文案测试，不改变解析、签名校验、生成、Secret 或警告行为。
- 不引入新依赖、网络请求、持久化行为或算法变更。
