## Why

Dev Toolbox 当前只能作为静态站点交付，最终用户仍需自行安装或配置 Web 服务器。提供自包含的 Go 启动器和一键打包流程，可以让 Windows 用户直接运行应用，同时保留浏览器内本地处理的使用方式。

## What Changes

- 新增 Go 本地启动器，将已构建的前端静态资源嵌入单个可执行文件。
- 启动器默认仅在本机回环地址的 `15173` 端口提供服务，并自动打开默认浏览器。
- 支持通过命令行参数覆盖监听端口，并对无效参数、端口占用和启动失败给出明确错误。
- 允许可执行文件同目录下的 `toolbox.config.json` 覆盖内嵌默认配置，便于交付后调整工具开关。
- 新增 PowerShell 一键打包脚本，依次完成前端构建、Go 可执行文件构建和发布包生成。
- 补充启动器测试和面向维护者、最终用户的使用说明。

## Capabilities

### New Capabilities

- `portable-local-launcher`: 定义自包含本地启动器的静态资源服务、浏览器启动、端口配置、运行时配置覆盖和错误处理行为。
- `portable-release-packaging`: 定义一键生成 Windows 便携发布包及其必要内容的构建行为。

### Modified Capabilities

- `runtime-tool-availability`: 运行时工具开关新增从可执行文件同目录外部配置加载的交付方式，同时保留内嵌默认配置回退。

## Impact

- 新增 Go 模块及启动器源码，并引入 Go 作为发布构建依赖；最终用户不需要安装 Go 或 Node.js。
- 新增 PowerShell 发布脚本和忽略的发布输出目录。
- 前端生产构建仍由现有 Vite 流程生成，静态资源随后嵌入可执行文件。
- 发布物主要面向 Windows；应用服务仅绑定回环地址，不对局域网公开。
