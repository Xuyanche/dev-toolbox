## Context

参见 [proposal.md](./proposal.md)。当前 JWT 页面已经实现解析/生成相反方向的等宽双列工作区、标题栏复制操作、Secret 标题栏操作以及 Payload/注册 Claim 共享视图。但生成算法仍位于设置列，解析端仍保留独立的算法/校验框体；同时网格虽然有目标高度，列自身仍可能滚动，子轨道也未获得可靠的确定高度，造成工作区底部空闲而格式化 Header 仍显示不全。

本次更新只调整规划中的交互与布局，不改变 JWT 解析、HMAC 校验、Header 派生、随机 Secret 生成算法、敏感数据生命周期或解析/生成状态隔离。

## Goals / Non-Goals

**Goals:**

- 让所有文本区复制操作位于字段标题栏，并使正文框完整用于文本显示或编辑。
- 让生成 Secret 的三个相关操作共享标题行，删除独立按钮行。
- 让解析 Payload 与注册 Claim 摘要复用一个可伸缩区域，最大化 Header/Payload 空间。
- 将生成算法移到工作区外的模式操作行，并把解析签名状态压缩为 Secret 下方的状态行。
- 让桌面两列实际填满等高工作区，保证常见四行格式化 Header 完整可见，并只在文本正文内部滚动。
- 保持窄屏自然堆叠、稳定反馈和键盘可访问性。

**Non-Goals:**

- 不允许编辑生成 Header，也不新增自定义 Header 字段。
- 不改变支持的算法、注册 Claim 集合或 Claim 格式化规则。
- 不新增确认弹窗、持久化、网络请求或依赖。
- 不把“生成 JWT / 清空生成”等工作区主操作合并进 Secret 标题栏。

## Decisions

### 1. 文本区采用标题栏操作组，而不是框内绝对定位

每个文本输入或输出区域由标题行和独立正文框组成。标题行左侧为字段名，右侧为操作组；复制图标属于操作组，不再属于正文框的定位上下文。正文框因此无需为图标保留顶部或右侧内边距，Header、Payload、JWT 和输入框均可使用完整宽度。

复制图标继续复用 MD5 页面同源的图形、尺寸和交互语义，并保留 button、aria-label、title、disabled 与 focus-visible。模式级共享反馈槽继续承载最近一次复制成功或失败，不把敏感值拼入反馈。标题行右侧若还有切换或 Secret 操作，则使用紧凑水平操作组；窄屏允许操作组整体换行，但操作顺序与 DOM 顺序保持一致。

移除“只读结果”“只读预览”“完整内容与注册 Claim”等标题辅助文本，因为其位置由可执行控件占用；字段本身的必要输入约束和安全提示不因此删除。

替代方案是继续把复制图标放在正文框内部并减少内边距，但图标仍会遮挡长文本或缩小可点击空间，因此不采用。

### 2. Payload 与注册 Claim 通过稳定双态视图复用正文区域

解析结果维护 Payload/注册 Claim 视图状态。成功解析后默认回到 Payload；清空或解析失败也重置为 Payload，以保证新结果首先展示完整内容。标题行在字段名与复制图标之间提供互斥的“Payload / 注册 Claim”切换控件。

Payload 状态渲染格式化的完整 Payload。注册 Claim 状态在同一个正文容器中渲染现有的格式化摘要，不再渲染第二个摘要框体。两种状态共用相同高度、边框和滚动规则，因此切换不会改变右列网格或工作区高度。没有注册 Claim 时显示空状态。

复制目标跟随当前视图：Payload 复制完整格式化 JSON；注册 Claim 复制与当前可见摘要对应的完整文本。当前视图为空或只有空状态提示时禁用复制。切换仅改变视图和复制目标，不修改解析数据或信任状态。

替代方案是使用展开/折叠摘要，但展开仍会侵占 Payload 高度且造成内容跳动，因此不采用。

### 3. Secret 专用操作集中到标题行

生成 Secret 标题行右侧按固定顺序渲染“生成”、复制图标、删除图标。“生成”保留文字以维持可发现性，并调用现有密码学安全随机生成流程；复制和删除使用图标按钮，在空值时禁用。删除调用现有仅清空生成 Secret 的状态边界，不清除 Claims、算法选择或已有 JWT。

解析 Secret 标题行只提供复制和删除图标。删除只清空解析 Secret 与相关复制反馈，保留 JWT 输入及已解析 Header/Payload。解析 Secret 继续使用 password 输入，复制读取状态中的完整值而非 DOM 展示文本。

删除图标使用与复制图标一致的按钮轮廓、悬停、禁用和焦点样式，并提供明确 aria-label 与 title。由于删除 Secret 可立即通过输入或生成恢复，且用户已直接点击专用图标，本次不增加确认步骤。

替代方案是把三个操作做成图标，然而“生成”仅靠图标难以与“生成 JWT”区分，因此保留文字按钮。

### 4. 将释放的空间优先分配给 Header 与 Payload

删除生成 Secret 独立操作行、框内图标预留空间和注册 Claim 独立框后，保持工作区外壳高度不变，把释放的垂直空间交给 Header/Payload 网格轨道。Payload 通常更长，继续获得高于 Header 的伸缩权重；两者各自内部滚动。生成模式左列同样缩减 Secret 轨道和固定操作轨道占用，使 Header 预览与 Payload 输入获得更多剩余高度。

桌面端两个模式继续共享同一工作区高度与等宽列定义。窄屏断点取消固定高度和伸缩轨道，标题栏可换行、正文按自然高度堆叠，不通过视觉 order 改变键盘或阅读顺序。

替代方案是进一步提高整个白色工作区高度，但这会削弱两个模式在常见视口中的完整可见性；本次先重新分配已有空间。

### 5. 生成算法属于模式级操作，不占用生成设置列

生成算法选择器与“操作 解析/生成”位于同一工作区外部工具行，并靠右显示；它只在生成模式挂载。算法状态与签名逻辑保持不变，切换到解析模式只隐藏控件，不重置选择。窄屏时工具行允许换行，算法仍处于白色主要工作区之外。

解析模式不再派生或展示独立的算法字段，因为完整 Header 已包含 `alg`。这减少重复信息，也让右列从 Header 直接开始。

替代方案是在生成设置列压缩算法选择器，但即使压缩仍会消耗固定轨道，并妨碍解析/生成两种正文区域获得一致的空间模型，因此不采用。

### 6. 解析签名状态成为 Secret 的动态辅助行

移除解析端“签名算法/签名校验”框体，把现有有效、无效、未校验、无签名和不支持算法等状态渲染为解析 Secret 下方的无边框状态行，沿用其语义颜色。该状态行取代静态的 UTF-8 编码说明；Secret 输入自身改用“UTF-8文本密钥，留空则不做校验”占位文案表达输入约束。

解析成功后记录本次校验所使用的 Secret 快照，或维护等价的 trust-dirty 状态。Secret 的输入事件和删除操作若使当前值偏离该快照，立即隐藏旧的有效、无效或其他结论，改为“Secret 已更改，请重新解析以更新签名状态。”；解析内容不清除。再次执行解析后，按当前 Secret 重算状态并清除 dirty 标记。尚未解析时可显示中性的“解析后显示签名校验状态。”。

替代方案是 Secret 修改时自动重新校验，但当前页面的主要解析动作是显式提交；自动校验会改变既有交互和错误时机，因此不采用。

### 7. 用确定高度链路填满桌面工作区

桌面端从白色工作区外壳到双列网格再到每列建立连续的确定高度与 `min-height: 0` 约束。双列网格占据外壳全部剩余空间，每列使用 `overflow: hidden`，不再让整列滚动；只有 JWT、Header 和 Payload 等正文元素使用 `overflow: auto`。

解析右列移除算法/校验轨道后，使用 Header 最小轨道、Payload 弹性轨道、Secret 与状态自动轨道。Header 最小高度按字段标题加常见四行格式化 JSON 计算，约为 150px；内容异常超长时才在 Header 正文内部滚动。生成左列移除算法轨道后采用同样的 Header 最小值，Payload 获得主要剩余空间，Secret、警告、操作和反馈使用内容高度。两列通过拉伸填满共同网格高度，避免底部未使用空间。

移动端断点撤销确定高度、`overflow: hidden` 和桌面网格轨道，恢复 `height: auto`、自然内容高度及语义顺序堆叠，避免小屏内容被裁切。

替代方案是继续给列设置 `overflow: auto`，但这会把固定标题和 Secret 操作一起卷走，并掩盖子网格没有实际填充的问题，因此不采用。

## Risks / Trade-offs

- [标题栏同时包含切换与复制控件，在窄宽度下可能拥挤] → 操作组允许整体换行，并保持足够触控尺寸和可见焦点。
- [注册 Claim 摘要不是原始 JSON，复制结果可能被误认为完整 Payload] → 复制反馈明确命名“注册 Claim”，且复制目标始终跟随可见视图。
- [图标删除的含义不如文字明显] → 使用通用删除图形、可访问名称、悬停说明和空值禁用；“生成”仍保留文字。
- [解析 Secret 修改后保留旧解析内容可能让用户混淆内容与校验] → 立即撤销旧签名结论并显示需要重新解析的状态，只有显式重新解析才恢复有效/无效等结论。
- [确定高度链路或 `overflow: hidden` 配置遗漏会裁切内容] → 桌面端逐层设置 `min-height: 0`，仅正文滚动；移动端明确撤销固定高度和裁切规则。
- [模式工具行加入算法后在窄宽度下拥挤] → 工具行允许换行，算法保持完整标签和可访问选择器，且不进入主要工作区。
- [标题辅助说明移除后只读属性不再显式写出] → 只读结果仍使用不可编辑元素及对应字段名称，不添加误导性的编辑样式。

## Migration Plan

1. 将可复用复制组件拆分为标题栏操作按钮与不含绝对定位的正文容器。
2. 迁移全部 JWT 文本区复制入口并移除冲突的标题辅助说明。
3. 添加 Payload/注册 Claim 视图状态、稳定共享正文容器及当前视图复制值。
4. 把生成和解析 Secret 操作迁移到标题行，并删除生成 Secret 独立操作行。
5. 调整桌面网格权重和窄屏标题栏换行规则，执行桌面与移动端视觉核对。
6. 将生成算法移动到模式操作行，并移除解析算法/校验框体。
7. 将解析签名状态迁移到 Secret 下方，添加 Secret 变更后的信任状态失效逻辑和新占位文案。
8. 建立桌面确定高度链路、Header 最小轨道和正文级滚动，并在移动断点恢复自然高度。
9. 更新测试并运行完整验证。若需回滚，可恢复原算法位置、解析校验框体和列级滚动；无需迁移任何数据。
