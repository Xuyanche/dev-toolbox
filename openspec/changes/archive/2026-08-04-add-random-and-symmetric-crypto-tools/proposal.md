## Why

当前工具箱缺少常用的随机取值与对称加解密能力，用户需要离开本地工具箱才能完成掷骰、批量随机数生成以及 AES、DES、SM4 数据处理。将这些能力补充到现有导航前部，可以让高频开发和调试任务继续在浏览器本地完成。

## What Changes

- 新增一级分组“随机数工具”，包含“色子模拟器”和“随机数生成器”。
- 色子模拟器支持可视化组合任意数量的 d2、d6、d8、d10、d12、d20、d100 色子，也支持通过 `2d6` 一类表达式快速配置，并展示每颗色子的点数和总点数。
- 随机数生成器支持设置范围、生成数量、整数或浮点数、结果是否唯一；默认生成范围 1–100 内的 1 个唯一整数。
- 新增一级分组“对称加密”，包含 AES、DES、SM4 加解密工具；支持以 HEX 或 Base64 提供密钥，并根据算法选择加密模式、填充模式、IV/偏移及相关参数。
- 调整桌面端和移动端导航顺序，使“随机数工具”和“对称加密”均位于现有“非对称加密”之前，同时保留后续现有分组的相对顺序。
- 优化随机数和骰子工具的紧凑布局，为两个结果区增加清空操作，并将骰子初始组合设为 `1d6`。
- 将桌面左侧一级分组改为单分组展开的可折叠导航，减少工具增多后的纵向滚动；统一提升所有工具面板标题的字号、字形和视觉层级。
- 所有随机与密码学处理继续在浏览器本地执行，不上传输入、密钥或结果。

## Capabilities

### New Capabilities

- `dice-simulator`: 定义可视化骰子组合、骰子表达式解析、投掷及逐颗结果和总点数展示。
- `random-number-generator`: 定义带范围、数量、数值类型和唯一性约束的随机数生成行为及默认值。
- `symmetric-cryptography`: 定义 AES、DES、SM4 的参数化加解密、密钥/IV 编码、校验与本地处理行为。

### Modified Capabilities

- `grouped-tool-navigation`: 在桌面端与移动端导航中加入两个新一级分组和五个子工具，并将它们排列在“非对称加密”之前。

## Impact

- 影响 React 应用外壳中的工具标识、分组定义、默认工具选择、桌面及移动导航和浏览器能力提示。
- 影响共享面板标题样式、随机数/骰子控件布局、结果操作以及桌面导航展开状态。
- 新增随机数、骰子和对称密码功能模块、界面组件、样式及单元/交互测试。
- 对称算法实现可能需要增加经过审查的浏览器端密码学依赖，尤其用于 Web Crypto API 未原生提供的 DES 与 SM4；产物必须保持纯前端和本地执行。
- 不引入服务端 API、持久化或网络传输。
