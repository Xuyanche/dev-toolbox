## Why

共享树增加了阅读配置、注释和直接修改的成本。用户已确认回到 IDE 风格的三栏文本融合，用可恢复的 YAML 字段重排减少顺序噪声，并补齐成熟编辑器的搜索替换和常用编辑能力。

## What Changes

- 保留“文本工具 → 文本对比”、默认启用、本地与离线运行、输入限制和页面内存生命周期。
- 左原文 / 可编辑融合结果 / 右原文成为唯一主视图，移除树与独立注释面板；逐行高亮、差异定位、采用箭头、锁定滚动和隐藏相同内容。
- 右侧可按左侧同路径映射字段顺序递归重排，独有字段稳定追加；列表不改，值不改，原始右侧保留并可恢复。
- 重排移动源片段与字段附属注释，不自动格式化；文档头尾保留，独立分组说明作为重排边界，模糊区域跳过并提示。
- 左右比较时默认只读，可显式编辑源文件；中间直接修改，支持 YAML 诊断和完整结果/草稿导出。
- 基于 CodeMirror 官方扩展增加当前栏/三栏搜索、替换、正则、整词、大小写、匹配统计、行号跳转、多光标、矩形选择、缩进、注释、行操作、折叠、换行、空白字符及状态栏。
- 格式化是独立显式操作，与重排分开；替换、采用、重排与中间编辑进入一致撤销历史。
- 对齐 IDEA 的融合操作：每侧行旁箭头采用、叉号忽略，双方独立处理；支持按点击顺序采用双方、Ctrl/Cmd+点击整块解决、结果区右键菜单、重置和 F7 导航。已处理的一侧及整块确认后的操作和高亮明确变灰。
- 移除示例入口和底部常驻下载区；两侧都忽略时从结果删除当前块并可撤销。顶栏合并名称、文件名、状态和图标操作，当前差异按钮浅色高亮；锁定滚动包含横向。结果栏下载图标打开文件名/换行符弹窗，取消不改草稿。
- 紧凑标题推广至其他工具页，合并 JSON 重复输入标题、简化 JWT 工作区标题和操作行，让正文使用更多空间；首页分类统一为能力介绍，移除文本对比专有跳转按钮。
- 差异导航与当前项操作合为编辑器上方的统一工具栏，增加全部未处理差异采用左/右；保留已确认选择及相同区手改，整批操作可一次撤销重做。
- 上方采用左/右分居两端并直接解决整块，移除工具栏单侧忽略，保留行旁独立操作；差异定位独立揭示三栏目标，避免滚动联动覆盖定位。README 的工具说明统一精简到行为约定。

## Capabilities

### New Capabilities

- `text-diff-merge`: 三栏文本融合与编辑器能力。
- `yaml-config-merge`: YAML 顺序辅助、注释和源片段保留、结果校验。

### Modified Capabilities

- `grouped-tool-navigation`: 保留原有独立一级菜单及运行时开关。
- `readable-typography`: 统一紧凑工具标题、可读说明及 JSON/JWT 的正文空间布局。

## Impact

复用 CodeMirror、行差异、局部事务、worker、严格 UTF-8 导入和导出；新增官方 search/autocomplete 扩展。原树形阶段为任务历史，当前交付以第 10–17 组任务及本轮规格为准。没有新后端或持久化。
