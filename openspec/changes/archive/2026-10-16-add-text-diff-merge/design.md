## Context

用户已确认使用普通文本融合界面，并以 YAML 字段重排辅助阅读。现有 CodeMirror、diffLines、YAML CST、worker 和事务映射均可复用；历史阶段的树界面退出主流程。参考 proposal.md。

## Goals / Non-Goals

**Goals:** 原始配置与注释直接可读；来源明确、编辑顺手；重排可恢复且不覆盖融合草稿。
**Non-Goals:** 不自动匹配列表项身份，不自动重排列表，不按注释文字推测归属，不在重排时格式化，不引入业务 schema 补全。

## Decisions

### 1. 三栏文本与差异事务

使用逐行比较生成差异块和相同区，显示整份原文及注释。中间初始沿用左侧，全部源差异仍待确认。采用箭头及工具条作用于当前块，手改通过 ChangeSet 映射范围并重新标记待确认；覆盖手改前提示。允许暂时无效 YAML 草稿，暂停自动采用并显示诊断。文本比较仍可用于检查不能结构重排的输入。

三份编辑器内部滚动，锁定时按相同区和差异锚点协调纵向位置，并同步横向像素偏移；关闭后两轴均独立。记录目标滚动后的实际位置以抑制反馈，短文本在边界钳制不会拉回长文本。隐藏相同只折叠各文档仍相同且未手改的区段，查找/定位自动揭示目标。窄屏使用左右/结果标签及当前差异候选；桌面尽量把高度留给文本。

日常滚动以源栏顶部可见行的文档位置映射到目标锚点，保持行内像素偏移；前置差异长度不等时，这种映射不能用于覆盖主动定位。选择差异时先暂停联动，各编辑器独立展开目标并居中显示起点，待三栏 CodeMirror 测量与后续滚动帧结束后记录实际位置、恢复联动。导航修订号防止快速切换时旧回调恢复过早；窄屏隐藏栏仍保留定位目标。上方“采用左侧/右侧”位于工具栏两端并直接完成整块双方决策，不显示单侧忽略；行旁和右键仍提供独立操作。

每块新增左右各自的 pending/accepted/ignored 状态。参考 [JetBrains 合并说明](https://www.jetbrains.com/help/idea/resolve-conflicts.html) 与官方 MergeConflictModel：箭头处理当前一侧，首次采用替换该块，第二侧采用按点击顺序追加；单侧叉号先记录忽略并保留当前内容；按本轮用户修订，两侧均忽略后删除中间对应差异块，支持一次撤销恢复删除前正文及部分决策。替换冲突双方都处理才确认；单侧新增/删除的采用和 EOL 差异可一步确认，文本块忽略仍分别处理两侧。失效范围不自动删除，双侧删除覆盖手改前允许取消。Ctrl/Cmd+点击及上方工具栏“采用左侧/右侧”相当于使用该侧解决整块，标记另一侧忽略。手动确认保留当前结果并处理双方。当前输入只有两份文件，没有共同祖先：中间继续沿用左侧，双侧忽略按用户选择删除对应块，不推断 Git 的非冲突变更或伪造三方自动合并。

一侧处理后该侧行高亮及箭头/叉号变灰且禁用；整块确认后结果高亮、上方当前项采用/确认及行旁采用/忽略按钮均变灰禁用。另提供“重置此差异”，恢复该块初始左侧内容和双方待处理状态，其他块保留；覆盖手改前确认，失效范围禁止重置。中间手改触及已确认块会重新开启双方。所有侧决策连同正文、范围与重排候选进入完整历史；重排精确匹配块保留独立侧状态。右键结果区提供使用左/右解决、忽略一侧、标记解决和重置，键盘菜单支持方向键和 Escape。F7/Shift+F7 导航差异，Ctrl/Cmd+Shift+Tab 切栏，Ctrl/Cmd+Shift+D 打开差异菜单。

差异选择、上下导航和当前项操作集中到编辑器上方同一工具栏；第二行显示当前两侧状态、阅读开关及批量操作，窄屏自然换行。“全部采用左/右”只处理 decision=pending 的块，包含部分采用/忽略、单侧增删及换行风格，不覆盖已确认块或相同区域手改，不受定位筛选影响。有手改的待处理块先集中确认一次；范围失效或合并结果超限时整批失败且历史不变。所有待处理替换构造一个 ChangeSet，整体映射范围与相同区，更新两侧决策；正文、EOL 与决策只记录一个历史快照，支持一次撤销重做，未处理数为零时批量按钮变灰。

### 2. 保留源片段的右侧重排

严格解析受支持单文档 YAML，通过同路径映射的标量键类型和值获得左侧顺序。递归处理映射，公共字段按左顺序排列，右独有字段按原右顺序追加；不进入列表。重排完整字段片段与附属注释，保留文档头尾及无关表示风格，必要时仅补分隔换行。流式映射与含独立分组注释的父映射跳过本级重排并给出路径提示，仍可处理安全的子映射。每次重排后重新解析并验证整个右侧配置签名不变。格式化是独立操作，显式允许表示风格变化。

重排与格式化的解析显式开启标量键支持，用类型和值组成内部身份，区分数字/布尔/null 与同名字符串；大整数不丢精度，不同数字源写法可按同值匹配，但保留右侧源写法。注释描述和递归查找使用相同的键身份，避免同名键的值或附属说明串项。历史结构合并适配器的默认字符串路径行为保留。结构检查携带失败节点的源偏移，转换成实际行列；重排提示区分左/右来源，不再将深层错误统一定位到根节点。

原始右侧 Source 不变，重排产生比较候选。恢复原始顺序、重排和格式化后的差异重算均保留当前融合结果。Snapshot 保存比较快照，使撤销/重做同时恢复候选顺序、范围和决策。重算以左侧到当前结果的文本映射定位新块，完全匹配的旧块保留决策，新划分块保守待确认；界面说明重定位而非声称所有历史决策原样保留。

重算同时保留匹配块的 safe/present 状态，检查来源到草稿的文本映射是否跨出新块边界；跨块编辑保持不可自动操作，避免采用或双侧忽略覆盖其他手改，仍允许显式手动确认与撤销。紧凑布局保留项目既有最低 12px 可读字号，正文默认 13px，压缩间距和重复控件而非缩小辅助信息。

### 3. CodeMirror 官方编辑能力

安装官方 search 与 autocomplete，复用已装 commands/language/view。工作区的紧凑搜索栏通过 SearchQuery 与搜索命令驱动当前栏或三栏，替换始终仅作用于当前可编辑栏。提供正则、大小写、整词、匹配数量、上一/下一结果；无效正则显示反馈。使用独立的查询状态高亮三个文档，搜索折叠范围可展开。

增加行号跳转、缩进/反缩进、自动缩进、注释切换、移动复制行、多选/矩形选择、括号匹配/补全和代码折叠。视图开关使用 Compartment，无需重建编辑器。底栏显示当前行列、选中字符数与行数；搜索、自动换行和更多入口保持精简，其他能力通过快捷键/菜单提供。YAML 默认两空格缩进，提供离开 Tab 缩进的键盘方式。

结果编辑只走外层会话历史，全部替换的单个 ChangeSet 对应一次撤销；左右源编辑保留编辑器本地历史。源改变暂停旧比较，不自动覆盖结果。

### 4. 输入、校验与异步边界

沿用每侧 2 MiB / 20,000 行、结果 4 MiB / 40,000 行及五秒 worker 任务预算；严格 UTF-8/BOM、NUL 检查、导入修订号、取消与过期结果丢弃。重排和格式化采用严格受支持解析；普通文本融合的结果检查 YAML 语法，不展开引用。错误保留草稿，未全部决策或无效时仅导出草稿。

开发环境显式将 Worker 独有的 `diff`、`yaml` 纳入 Vite `optimizeDeps.include`，避免第一次比较才发现依赖、预构建失效及页面重载中断任务。冷启动浏览器测试使用独立缓存验证首次比较完成且页面不重载。Worker 的构造、发送、模块错误、消息解码和无效响应分别反馈，携带可用的加载错误信息，统一终止 Worker 并清理超时；失败保留会话，刷新前提示保存草稿。

### 5. 紧凑顶栏与下载弹窗

工作区移除示例入口和常驻导出栏，编辑器顶栏合并名称、文件名、状态与图标操作；文件名截断时用 title 保留全文。所有图标有可访问名称与键盘焦点。压缩页面标题、单行顶栏和帮助说明，增加正文高度，窄屏仍切换文档标签。当前差异的行旁按钮使用浅色背景及边框高亮，已处理状态优先保持灰色禁用。

结果栏提供撤销/重做、复制和下载图标。下载以原生 modal dialog 显示文件名和换行符，进入时捕获完整正文及完成状态快照，取消/Escape 返回图标焦点；设置和下载不修改正文或合并决策，不写入会话历史。下载确认保存完整快照并记住文件名，换行转换仅影响导出文件。

共用 ToolHeader 样式推广相同紧凑规则：标题与说明并排或自然换行，隐藏装饰性英文眉题，说明保持 13px，正文输入字号不变。JSON 将重复输入标题与复制按钮合为面板标题栏，输入区域使用释放的空间。JWT 使用具名工作区区域代替重复视觉标题，模式、算法控件紧凑同列，保留字段名、签名/Secret 状态和提示。现有桌面剩余高度布局与窄屏自然流保持，首页移除专有工具跳转按钮，统一通过桌面或移动导航进入。

## Risks / Trade-offs

- [行差异块不一定对应完整 YAML 节点] → 结果持续校验，直接保留手工修复和撤销能力，不假设每次采用都保持语法有效。
- [分组说明归属不确定] → 跳过该映射本级重排并解释，不移动说明去猜测字段。
- [重排改变文本差异划分] → 草稿不变、快照可撤销，新块重新待确认。
- [原文表示差异仍存在] → 重排只处理顺序，格式化单独显式执行。

## Migration Plan

保留历史任务，第 10 组完成重排、快照事务和编辑器主界面，第 11 组补齐 IDEA 风格的每侧采用/忽略、可见灰色状态和重置。用注释/顺序/撤销回归、浏览器融合操作与编辑快捷键、四视口、离线与导出测试验收。不开启新的网络数据接口或浏览器存储。
