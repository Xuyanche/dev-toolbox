## Why

对称加密与编码工具都以长文本工作区为主要操作对象，但桌面页面会因工具标题、参数区、工作区和全局页脚叠加而产生文档级纵向滚动。将这些工作区型工具约束在单个桌面视口内，可以减少与实际操作无关的页面移动，并在不同工具之间提供一致的专注体验。

## What Changes

- 为对称加密组的 AES、DES、SM4，以及编码工具组的 URL、Unicode、Base64、JWT、JSON 提供统一桌面聚焦布局，使应用外层和主文档不产生纵向滚动。
- 让工具标题、参数或模式区、主要工作区、操作反馈和紧凑的全局页脚共同在动态视口高度内布局；超出空间的内容在当前工具功能区域内部滚动。
- 保持 JSON 输入与树形结构、JWT 正文区域、编码输入输出及对称加密明密文区域各自适合其交互的内部滚动行为，长内容不会撑高外层页面。
- 在窄视口、低高度视口、浏览器缩放或字体放大导致内容无法安全容纳时，继续采用自然文档滚动，避免控件被裁切或无法访问。
- 增加组内所有目标工具的状态与真实布局回归验证，确认目标桌面视口中无文档级纵向溢出，同时内部滚动和工具切换仍然可用。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `json-tool`: 将现有桌面首屏可访问要求收紧为在符合条件的桌面视口中不产生文档级纵向滚动，并明确低空间视口的可访问性回退行为。
- `toolbox-shell`: 为对称加密组与编码工具组的工作区型页面增加统一的桌面聚焦视口和内部滚动契约。

## Impact

- 主要影响 `src/shell/App.tsx` 的活动工具布局标识、对称加密工具的页面布局钩子，以及 `src/styles.css` 中各目标工作区的高度、溢出与页脚布局。
- 更新应用壳层、对称加密、文本编码、JWT 与 JSON 测试，并增加能够读取实际页面尺寸的浏览器布局验证。
- 不改变密码或编码算法、JSON/JWT 处理、复制行为、数据存储方式或外部依赖。
