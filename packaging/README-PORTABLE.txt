Dev Toolbox Windows 便携版
==========================

启动
----
双击 dev-toolbox.exe。程序会在本机启动服务，并自动打开默认浏览器。
默认访问地址：http://127.0.0.1:15173/

修改端口
--------
在当前目录打开 PowerShell，运行：

  .\dev-toolbox.exe --port 18080

端口必须是 1 至 65535 范围内未被占用的整数。服务始终只监听本机
127.0.0.1，不会向局域网或公网开放。

停止
----
在程序控制台中按 Ctrl+C，或者关闭控制台窗口。

工具开关
--------
可以编辑 EXE 同目录的 toolbox.config.json，然后刷新浏览器。该配置只控制
工具入口是否显示，不是访问控制或安全边界。配置文件缺失时，程序会使用
EXE 内嵌的默认配置。

常见问题
--------
1. 端口被占用：使用 --port 指定其他端口。
2. 浏览器没有自动打开：复制控制台显示的地址并手动访问。
3. Windows SmartScreen 提示：未签名的内部发布版本可能出现此提示。请先确认
   文件来自可信发布方；面向公众分发时应使用代码签名。

所有转换和加解密操作仍在浏览器本地完成，不会上传工具输入内容。
